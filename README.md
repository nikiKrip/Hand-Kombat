# Hand-Kombat
Gesture Recognition Project using js and python to create a mortal combat style game in which the opponent is an AI agent that learns and adapts from your mistakes and game gets increasingly difficult over time.
## To Launch the Application in the Terminal
### AI Service
Run the following commands
```
source venv/bin/activate
uvicorn main:app --reload
```
### Frontend
Run the following commands
```
npm run dev
```
### Backend
Run the following commands
```
node src/socket.js
```
